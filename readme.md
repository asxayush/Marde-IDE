## About

Marde AI is an AI-first code editor built from scratch with the MERN stack.
The goal is to bring an AI coding assistant, real-time collaboration, and a
cloud-based workspace into one place.

> ⚠️ This project is under active development. Things will break.

## Getting Started

### Prerequisites
- Node.js v18+
- MongoDB (local or Atlas)
- Git

### Installation

```bash
# Clone the repo
git clone https://github.com/asxayush/Marde-IDE.git
cd Marde-IDE

# Install client dependencies
cd client
npm install
```

### Environment Variables

Create a `.env` file in the `client` folder (aur server folder mein bhi, jab ban jaye):

```env
VITE_API_URL=http://localhost:5000

```



### Run locally

```bash
npm run dev
```
